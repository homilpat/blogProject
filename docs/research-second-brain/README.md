# Knowledge Hub 2.0 — Autonomous Research Second Brain

- 상태: 기획안, 구현 미착수
- 작성일: 2026-11-23
- 기준 저장소: [homilpat/blogProject](https://github.com/homilpat/blogProject), main (검토 기준 837b6efe8a3b4f0ebd4580c2c3852e37873962b2)
- 변경 원칙: 기존 기능 보존, 별도 기능 단위로 점진 확장, 코드 수정은 단계별 검토 후 진행

## 1. 한 줄 정의

**사용자가 직접 공부하고 작성한 책, 논문, 강의 및 연구 노트를 AI 에이전트가 자동으로 구조화하고 연결하여, 내부 지식을 근거로 연구 질문과 가설 후보를 도출하고, 반론과 지식 공백, 추가로 공부할 내용을 제안하는 개인 연구형 Second Brain.**

Knowledge Hub는 인터넷에서 정보를 대신 수집하는 범용 챗봇이 아니다. 사용자가 축적한 지식의 출처를 보존하고, **개인의 관점에서 새로운 연결**을 발견하는 도구다.

## 2. 문제와 사용자 가치

기존 개인 노트, 블로그, RAG의 한계:
1. 책과 논문을 읽은 뒤 작성한 요약이 문서별로 흩어지고, 관련 개념을 사용자가 직접 연결해야 한다.
2. 관련 노트를 검색하는 데 성공해도, 여러 문서의 주장과 전제를 조합한 연구 가설까지 발전시키기는 어렵다.
3. 생성형 AI는 개인이 공부하지 않은 외부 지식을 무심코 혼합하거나, 출처 없는 가설을 사실처럼 설명할 수 있다.
4. 연구 아이디어를 떠올려도 이를 검증하려면 무엇을 더 알아야 하는지 체계적으로 추적하기 어렵다.

**핵심 사용 경험**
- 내가 쓴 요약 노트를 등록하면 별도 분야/폴더 설정 없이 관련 개념과 기존 노트의 연결이 제안 또는 생성된다.
- "이전에 읽은 두 논문을 조합할 수 있어?"라고 질문하면 내부 근거와 연결 경로를 제시한다.
- "내 지식에서 실험 가능한 가설을 찾아줘"라고 요청하면 근거, 추론, 반론, 검증 방법, 현재 지식 공백을 분리하여 보여준다.
- 외부 논문을 검색하지 않는 초기 버전은 내부에 근거가 없을 경우 **"현재 등록된 지식에서 필요한 근거를 찾지 못했습니다. 외부 지식 또는 추가 학습 자료가 필요합니다."**라고 알린다. 외부 정보로 답변을 채우지 않는다.
- 요청 시 현재 등록된 노트에서 학습 문제를 출제하고 답변을 평가한다.

## 3. 제품 원칙

1. **개인 지식 우선**: 기본 검색 범위는 등록된 노트 및 승인된 내부 자료만 사용. 초기 버전에서 외부 웹 검색 도구 없음.
2. **사용자 입력과 AI 추론 분리**: 노트의 원문, 노트에서 추출한 주장, 에이전트가 제안한 가설은 상태와 출처가 다르다.
3. **신규성 과장 금지**: 개인 지식에 새롭다고 학문적으로 새로운 연구는 아니다. 외부 문헌 조사 없이 신규성을 확정하지 않는다.
4. **지식 부족을 정확히 표현**: 검색 실패는 부재의 증거가 아니다. 추가 내부 탐색 뒤에도 못 찾으면 '검색 범위 내 근거 미확인'으로 응답한다.
5. **자율 탐색, 통제된 쓰기**: 도구 선택과 내부 탐색은 자율적, 데이터 삭제/병합 및 기존 사실의 변경은 승인 또는 엄격한 검증 필요.
6. **그래프는 목적이 아닌 도구**: 일반 벡터 RAG 대비 유의미한 성능 개선이 평가되지 않으면 그래프 전략을 재검토한다.
7. **소규모 로컬 모델 적합성 검증**: JSON 스키마 준수, 추출 정확도, 지연시간을 실제 환경에서 측정한다. 무조건 동작한다고 가정하지 않는다.
8. **사용자별 격리**: 모든 인덱스, 노드, 관계, 연구 이력은 소유자 범위로 검색하고 수정한다.
9. **변경 추적**: 노트 수정/삭제 시 파생 관계 및 가설의 근거 상태를 재계산하거나 무효화한다.

## 4. 핵심 워크플로

### 4.1 지식 수집 및 자동 연결

1. 사용자가 책, 논문 등 출처 메타데이터와 직접 작성한 요약 노트를 등록한다.
2. 원문 노트를 영속 저장하고 비동기 인덱싱 작업을 기록한다.
3. 내용에서 개념과 주장, 조건, 불확실성을 구조화 추출한다.
4. 기존 노드와 의미 및 문맥을 비교해 동일 개념 또는 연결 후보를 제안한다.
5. 근거 위치와 검증 결과를 가진 관계만 활성 그래프에 반영한다.
6. 변경 이력을 남기고 관련 지식 탐색을 갱신한다.
7. 새로운 연결이 연구 가치가 있을 경우 **가설 후보**를 별도 저장할 수 있으나, 매번 강제로 생성하지 않는다.

### 4.2 내부 지식 질문

질문 해석 → 내부 벡터 검색 → 그래프 관계 확장 → 필요한 경우 근거 재검색 → 근거 조합 → 주장 단위 검증 → 답변.

가능한 부분만 근거를 제시하여 답하고, 부족한 부분은 분명하게 밝힌다. 노트 내용에서 합리적으로 도출 가능한 추론은 명시적으로 추론으로 표시한다.

### 4.3 연구 인사이트 생성

연구 의도 분석 → 후보 연결 탐색 → 검증 가능한 가설 후보 생성 → 독립적인 반론/약점 검토 → 필요 시 재탐색 → 검증 설계와 지식 공백 추출 → 보고서 저장.

보고서는 **가설, 기여한 노트/주장, 추론 연결, 예상 반론, 검증 방법, 추가 학습 항목, 검증 상태**를 포함한다.

## 5. 명시적 비범위 (초기 릴리스)

- 외부 웹 검색, 논문 자동 크롤링, 자동 학술 신규성 판정
- 사용자가 업로드하지 않은 책/논문 원문에 대한 사실 검증
- 원본 대비 학습 요약 누락률 평가
- 무제한 자율 실험/코드 실행, 논문 자동 출판
- 별도 학습 분야 폴더 자동 생성/강제 분류
- 성능 검증 이전의 Neo4j 및 대규모 멀티에이전트 도입

## 6. 현재 코드의 활용 범위

| 영역 | 기존 구현 | 전환 계획 |
| --- | --- | --- |
| Next.js | 게시글, TipTap, AI 채팅 | 노트 편집 재활용, 연구 대시보드 추가 |
| Spring Boot | 인증, 게시글 CRUD, RAG 연동 | 노트 소유권, 연구 실행 API, 상태 조회 |
| MySQL | users, posts, categories, conversations | source, claim, concept, relation, hypothesis 등 확장 |
| FastAPI | QueryPlanner, EvidenceRetriever, ClaimJudge, NoveltyJudge | 지식 구축기와 연구 오케스트레이터 분리 |
| Qdrant + BGE-M3 | 벡터 검색 및 재색인 | 사용자 범위, 노트 버전, 근거 위치 메타데이터 |
| LM Studio 로컬 LLM | 답변 및 검증 | 구조화 추출/가설 생성/비판 성능을 별도 측정 |

**현재 미구현**: 지식그래프, 자율 연구 루프, 가설/지식 공백 전용 저장 구조, 요청형 학습 평가. 별도 작업 브랜치의 실험 결과가 현재 main 구현을 뜻하지는 않는다.
